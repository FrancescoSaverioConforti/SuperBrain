Companion to the Findings Policy ([[d93lx]]). Every significant evaluation (real-repo validation, benchmark, mutation campaign, security/performance/regression test, comparative evaluation, smoke test) must be recorded at docs/research/evaluations/<ID>.md (B2-EVAL-xxx scheme) with: date, SuperBrain commit, external repo+exact commit+license, methodology, raw counts (with denominators, never a bare percentage), derived metrics, pass/fail, interpretation, limitations, linked findings, literature refs when available. Every claim tagged exactly one of Measured/Manually validated/Inferred/Estimated — never present Estimated/Inferred as Measured. B2 is NOT considered validated by one codebase — before closure, a multi-domain suite is required covering ML/DL, data/scientific, backend/API, frontend/UI, desktop/UI, Rust/systems, C++/C#, full-stack, CLI/tooling, each with explicit compatible license. Must always be reconstructable: Evaluation -> Finding -> Root Cause -> Fix -> Regression Test -> Re-evaluation. Research integrity: report failure cases/false positives/negatives/rejected approaches alongside favorable results, never cherry-pick.
