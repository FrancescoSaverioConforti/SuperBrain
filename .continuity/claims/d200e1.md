Metric runner calls index::search/api::search directly as a native Rust binary (crates/api/examples/b3_metric_runner.rs) with metrics logic in a separate testable module (crates/api/src/metrics.rs) — never duplicates retrieval logic, never bridges to Python. Builds a real temp vault/index from the B3 corpus, reads split labels, excludes canary-isolation-probe by id, computes Recall@10/nDCG@10/bootstrap-CI/category+difficulty breakdowns/abstention metrics, writes JSON report to eval/results/B3/. Python (eval/rag/*.py) stays as-is for B3.1/B3.2 tooling only.
