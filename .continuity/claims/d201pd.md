Design approved with 3 methodological corrections before implementation: (1) Recall@10 must be |relevant ∩ top10| / |relevant|, NOT a 0/1 hit indicator (the first draft wrongly computed Hit@10 and called it Recall@10) — Hit@10 kept only as an optional diagnostic, never used for thresholds. (2) nDCG formula frozen verbatim: gain(rel)=2^rel-1, DCG@10=Σ(2^rel_i-1)/log2(i+1), IDCG from the query's own graded_relevance sorted descending truncated to 10, nDCG=DCG/IDCG — copied verbatim into frozen-config.json so it can't drift later. (3) Abstention precision/recall/F1 must be null (not 0.0) when their denominator is zero; bootstrap CI only counts resamples where the metric is defined, reports valid_resamples/total_resamples, and marks low_confidence/null CI if valid_resamples is too low. Rest of prior design (native Rust runner, real api::search, pure metrics module, deterministic seeded bootstrap, category/difficulty breakdown+n, per-query evidence, dev→calibration→STOP before freeze, no final-test/MCP/merge/tag/push) stands unchanged.
