  B2-EVAL-008 paused on B2-ID-009 (Critical): C# method_declaration extraction
  misnames methods whose return type is a simple non-generic named type (e.g.
  PolicyBuilder Handle&lt;T&gt;() extracted as "PolicyBuilder", not "Handle"),
  because method_declaration has two direct identifier children (return type,
  then name) and the extractor takes the first match instead of using the
  grammar's own named "name" field. Confirmed C#-specific via cross-language
  probe (Rust/Python/JS/TS/C++ all structurally immune, each for a different
  confirmed reason). Fix not implemented; user ruled: open finding, audit scope,
  stop and report before touching code.
