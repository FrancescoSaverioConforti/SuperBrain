brain-api-audit-worker is wired into mcp-server as a [dev-dependencies] entry, used only by examples/serve_stdio.rs. SuperBrainMcpServer (the library type) stays unaware the worker crate exists; injection is only ever via the existing .with_audit_sink(Arc<dyn AuditSink>) builder. This keeps tests/no_bypass.rs's production dependency allowlist untouched -- a deliberate user call during M5 Task 6, ruling out the alternative of adding it as a production dependency with library-level ownership.
