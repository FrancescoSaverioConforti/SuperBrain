User explicitly revised the MVP spec's CLI-only write boundary (spec line 70) to support remote agents on other machines while still forbidding autonomous/self-approved MCP writes. Flow: Agent (any PC) → MCP → Brain API creates PendingWriteProposal (status Pending/Approved/Rejected/Expired) → only a trusted human surface can move it to Approved → Brain service executes via existing storage/policy path → audit/provenance. B6 UI will add human-initiated writes (no proposal needed) distinct from agent-initiated proposals; both still go through Brain API/policy/storage, UI never touches storage directly. B5 freezes this model + implements proposal service + minimal CLI approval for E2E; does not build the UI.
